8 Punkt Grid

Ausflug ins Thema UI Design.

Wenn Sie Produktdesigner oder User Experience Designer sind, haben Sie wahrscheinlich schon einmal den Begriff Rastersystem gehört. In diesem Artikel bespreche ich die Verwendung der gängigsten 8-Punkt-Layoutrastersysteme. Denn konsistente und skalierbare Abstände helfen Designern und Entwicklern, deutlich schneller an einem Projekt zu arbeiten.
