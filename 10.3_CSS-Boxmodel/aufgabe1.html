CSS Box Model

Was ist das Box Model?

Jedes Element auf einer Webseite ist eine rechteckige Box. Das Box Model beschreibt, wie Inhalt, Innenabstand, Rahmen und Außenabstand zusammenspielen.

Merke: Padding ist der Abstand innerhalb des Rahmens, Margin ist der Abstand außerhalb.

Breite und box-sizing

Mit box-sizing: border-box wird Padding und Border in die angegebene Breite eingerechnet – das erleichtert das Layout erheblich.

Ohne border-box: width + padding + border = tatsächliche Breite.
Mit border-box: width = tatsächliche Breite.
